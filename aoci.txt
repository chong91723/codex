#【部署】Python 3.11+ 标准库运行 python3 web/start.py --deepseek；原生运行时来自固定 Codex 源码的独立构建；可选分析 MCP 使用独立 Python 环境及本机 ECharts；浏览器验收用 Playwright。
#【系统】面向数据分析人员的自然语言分析工作台；Python HTTP/WebSocket 转发原生 app-server，原生 Agent 调用只读分析 MCP，原生 HTML/JS 在对话中显示依据、图表和报告；不替代 Codex Agent 循环，不改 upstream 或 native。

#【约束】实际验证模型使用 deepseek-flash；数值发布匹配执行证据，用户确认的指标规则才证明特定口径；记忆不能代替有效业务知识或批准冲突；历史报告保留原文并提示复核。

#A口径: 只列本文件对外提供的API、入口或协议；不列内部辅助函数。
#S纪律: 只保留文件名、标签、F、R、A无法推导但修改必须知道的约束；不写版本日期或演进叙事。
